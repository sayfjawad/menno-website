Je omgeving draait. Deze pagina wordt geserveerd vanuit /workspace/menno-website op poort 3000 en is live op menno.sdai.nl.

Aan de slag met je agent:

  1. Open de browser-IDE of SSH in je omgeving.
  2. Laat de agent deze site verbouwen tot jouw web-app.
  3. Sla het werk op: git add -A && git commit -m "..." && git push

Je code staat in github.com/sayfjawad/menno-website. Vervang gerust server.js en index.html door je eigen framework — blijf alleen op 0.0.0.0:3000 serveren.
